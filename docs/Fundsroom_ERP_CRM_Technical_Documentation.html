1. Executive Summary

This technical submission represents a complete, production-grade Mini ERP + CRM Operations Portal engineered for Fundsroom Infotech Pvt. Ltd. to streamline wholesale B2B distribution, customer relationship management, stock audit trails, and sales challan generation.

The application resolves key business challenges:

  • Preventing Negative Stock: Database-level transactional guards (prisma.$transaction) validate real-time inventory counts before confirmation.
  • Historical Financial Protection: Sales challans preserve snapshot unit prices (unitPriceSnapshot) so financial records remain accurate if catalog prices change later.
  • Role-Based Access Control: Strict permission enforcement across 4 organizational roles (ADMIN, SALES, WAREHOUSE, ACCOUNTS).

5. Atomic Transactional Stock Deduction Code Highlight

The core feature of the system is the database transaction executed when a sales challan is confirmed: 

// challanService.ts
return await prisma.$transaction(async (tx) => {
  for (const item of challan.items) {
    const product = await tx.product.findUnique({ where: { id: item.productId } });
    if (!product || product.currentStock < item.quantity) {
      throw new AppError(`Insufficient stock for '${item.productNameSnapshot}'. Available: ${product?.currentStock || 0}`, 400);
    }

    // Decrement stock atomically
    await tx.product.update({
      where: { id: item.productId },
      data: { currentStock: { decrement: item.quantity } },
    });

    // Log outward stock movement
    await tx.stockMovement.create({
      data: {
        productId: item.productId,
        quantity: item.quantity,
        movementType: 'OUT',
        reason: `Sales Challan Confirmation: ${challan.challanNumber}`,
        createdBy: userId,
      },
    });
  }

  return await tx.challan.update({
    where: { id: challanId },
    data: { status: 'CONFIRMED' },
  });
});
